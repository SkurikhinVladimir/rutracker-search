# rutracker-search

Не нашёл готового репозитория, с которым локальный агент мог бы работать с
RuTracker. Сделал не самый оптимальный, но рабочий способ обойти антибот-защиту
(Cloudflare): код управляет настоящим Chrome и умеет искать раздачи и скачивать
`.torrent`.

Выкладываю, чтобы сэкономить время, если вы (или ваш агент) ищете готовое
решение для этой задачи.

## Инструкция для агента

Нужны компьютер с экраном, Chrome, Python 3.13+ и `uv`. Установка: `uv sync`.

Используй код напрямую, запуская из папки проекта через `uv run`:

```python
from rutracker_search import RuTracker

with RuTracker() as rt:
    results = rt.search("python")
    rt.download(results[0]["topic_id"], "book.torrent")
```

Методы и формат результата смотри в `rutracker_search.py`. Для серии запросов
создай `RuTracker()` один раз, а не на каждый запрос.

### Вход и Cloudflare

- Нужен аккаунт RuTracker. Логин и пароль можно положить в `.env`
  (шаблон — `.env.example`), иначе пользователь входит вручную в окне Chrome.
  Сессия сохраняется, при следующих запусках вход не нужен.
- Если в консоль выведено «Пройдите проверку или войдите в окне Chrome»,
  не перезапускай скрипт. Попроси пользователя пройти проверку в открытом окне,
  клиент подождёт и продолжит сам.
- Проверка привязана к IP: окно Chrome должно выходить в сеть так же, как
  пользователь.

# rutracker-simple

Не нашёл готового репозитория, с которым локальный агент мог бы работать с
RuTracker. Сделал не самый оптимальный, но рабочий способ обойти антибот-защиту
(Cloudflare): код управляет настоящим Chrome и умеет искать раздачи и скачивать
`.torrent`.

Выкладываю, чтобы сэкономить время, если вы (или ваш агент) ищете готовое
решение для этой задачи. Разбирать код не нужно, ниже инструкция.

## Инструкция для агента

Требования: компьютер с графической оболочкой, Chrome, Python 3.13+, `uv`.
На сервере без экрана и в headless-режиме не заработает: Cloudflare иногда
требует, чтобы человек прошёл проверку в окне.

Установка, один раз:

```bash
uv sync
```

Работа с кодом напрямую, запускать из папки проекта через `uv run`:

```python
from rutracker_simple import RuTracker

with RuTracker() as rt:
    results = rt.search("python", max_pages=2)  # 50 раздач на страницу
    rt.download(results[0]["topic_id"], "book.torrent")
```

- `search(query, max_pages=1)` возвращает список словарей: `topic_id`, `title`,
  `category`, `author`, `size_bytes`, `seeds`, `leeches`, `added` (unix time),
  `url`. Пустая выдача — пустой список.
- `download(topic_id, path=None)` сохраняет `.torrent` (по умолчанию
  `<topic_id>.torrent` в текущей папке) и возвращает его байты.
- Для серии запросов создавайте `RuTracker()` один раз: окно Chrome открывается
  при создании и закрывается при выходе из `with`.

Из командной строки:

```bash
uv run python rutracker_simple.py search "python"
uv run python rutracker_simple.py download 6921674 book.torrent
```

Ограничения: CLI берёт только первую страницу поиска (50 раздач), а подбирать
раздачи по сидам и размеру надо по полям результата.

### Вход и проверка Cloudflare

- Нужен аккаунт RuTracker. Логин и пароль можно положить в `.env`
  (шаблон — `.env.example`), тогда клиент входит сам. Иначе пользователь
  входит вручную в открывшемся окне. Сессия сохраняется в `.chrome-profile/`,
  при следующих запусках вход не нужен.
- Если в консоль выведено «Пройдите проверку или войдите в окне Chrome», не
  перезапускайте скрипт и не повторяйте запрос. Попросите пользователя
  пройти проверку в открытом окне: клиент ждёт до 5 минут (параметр `timeout`)
  и продолжит сам.
- Проверка Cloudflare привязана к IP. Если окно Chrome выходит в сеть иначе,
  чем пользователь (например, через VPN), проверка не пройдёт.
- Если `undetected-chromedriver` не подходит к версии Chrome, передайте её
  главный номер: `RuTracker(chrome_version=140)`.
